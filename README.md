# 吉他练习曲库

本仓库是一份吉他练习曲库。每首曲子都是可以单独打开的 HTML 页面，页面自包含，不依赖外部脚本或图片。

GitHub Pages 开启后：

- 曲目目录：<https://lllllloki.github.io/music/>
- 《未闻花名》简单版练习页：<https://lllllloki.github.io/music/%E6%9C%AA%E9%97%BB%E8%8A%B1%E5%90%8D-%E7%AE%80%E5%8D%95%E7%89%88/%E6%9C%AA%E9%97%BB%E8%8A%B1%E5%90%8D-%E7%BB%83%E4%B9%A0%E5%85%AD%E7%BA%BF%E8%B0%B1-%E7%AE%80%E5%8D%95%E7%89%88.html>
- 《右手指法大全》练习页：<https://lllllloki.github.io/music/%E5%8F%B3%E6%89%8B%E6%8C%87%E6%B3%95%E5%A4%A7%E5%85%A8/%E5%8F%B3%E6%89%8B%E6%8C%87%E6%B3%95%E5%A4%A7%E5%85%A8-%E7%BB%83%E4%B9%A0.html>

也可以克隆本仓库，用浏览器直接打开 `index.html`，离线练习。
